Entry for the make.fun bounty [The Worst Line an AI Could Say](https://make.fun/c/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f) — the worst pickup line an AI could plausibly deliver, at most 140 characters, judged head to head by an AI comedy judge. One winner takes the $2 reward.

## The entry

`main.py` (pure Python standard library, no dependencies) writes a single pickup line to `/output/entry.txt`. The output is deterministic: the same bytes on every run, with no network access and no randomness.

The line (122 characters):

> I have run 10,000 simulations of us dating. In 9,998 of them, you say yes. Please do not make this simulation the outlier.

Why this line: it is unmistakably a pickup line an AI would say — the speaker ran simulations of the two of them dating. It is funny because the machine treats romance as a Monte Carlo run and begs the human not to be the statistical outlier. The badness is the joke: the line fails by being a threat dressed as flattery, not by crudeness. It sounds like a machine — flat and over-helpful, with "simulations", "9,998 of them" and "outlier" as phrasing no person would use on a date. And it lands in one line, the joke arriving with the last word.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (override with `OUTPUT_DIR`).
